# Artflow : Art Gallery Managment System
ArtFlow is a web-based application designed to streamline the management and presentation of an art gallery's collection. Its primary purpose is to provide gallery administrators with a centralized platform to manage artists, artworks, inventory, and customer inquiries.  Gallery staff can easily update the online catalog, track artwork availability, and browse the avaliable artist. 

## Features Implemented
- Users can Signup and Login as Admin
-Users can update the status of artwork in the inventory
-Users can delete art from the database
- Users can Browse the artist within the inventory 

## Features Not Implemented

-The art does have prices displayed but not a way to buy them
